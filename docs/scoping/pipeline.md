# Scoping: the data pipeline

6B evaluations (`.claude/skills/six-b/SKILL.md`) for the steps that turn
Door43 sources into `dist/tc-mobile/`. Findings marked _(reported)_ come from
a read-only survey of unfoldingWord repos on 2026-10-28 and have not been
re-run here; everything else was run or read directly on 2026-10-28.

| Borrow | applied  | BSB USFM, `Worldview/en_bsb` at `7abbfafa`: 3,016 `\s1` headings (measured). | Build  | minimal  | The heading-to-span rule with the Breaks above as tests. ## 2. Consensus check

The build plan compares each BSB title with eight copyrighted English Bibles
and overrides the title when 60% of them (at least 3) agree on another
wording.

| Step   | Verdict  | Evidence / justification                                                                                                                                                                                                                                                                                                                                                                   |
| ------ | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Borrow | skipped  | No uW text has the coverage: `en_ult` at `04e15203` has no section headings; `en_ust` at `6ca02d44` has 129 (measured), against 3,016 in BSB. The eight versions are copyrighted, so not borrowable under this repo's licence rule.                                                                                                                                                        |
| Bend   | skipped  | FIA's pericopes could cross-check boundaries, but its schema has no pericope titles, access needs a key nobody here holds, and neither FIA repo has a licence _(reported)_.                                                                                                                                                                                                                |
| Break  | observed | The pilot reached no override, but that is 0 of 18 pericope titles: too small a sample to call the rate zero (by the rule of three, a rate up to about 1 in 6 is consistent with it). The rule as written is ambiguous: 60% of 8 versions is 5, yet the plan also says "at least 3"; to ask. Bulk reading of the eight versions was rate-limited during the pilot (build plan).            |
| Beget  | skipped  | Nobody to hand it to.                                                                                                                                                                                                                                                                                                                                                                      |
| Bide   | n/a      |                                                                                                                                                                                                                                                                                                                                                                                            |
| Build  | none     | **Recommendation: leave the consensus check out of v0.1.** BSB titles ship as-is with `source: "bsb-headings"`, and human review flags the ones that need changing. The override rate is unmeasured, the source is 9,500 copyrighted pages, every title carries its source, and overrides can be added in a later version; so defer rather than build now. A decision for servant.bible#1. |

Reversibility: forward = low; backward = low. Overrides can be added in a
later version; titles carry their source.
