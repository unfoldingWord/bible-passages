# 0006: v0.1.0 ships in English only

- **Status:** accepted
- **Date:** 2026-11-05
- **Decided by:** the maintainer, on #244 (decision 1 there). Narrows ADR
  [0003](0003-v0.1-scope-and-titles.md) decision 1 for the first tag.

## Decision

1. **v0.1.0 carries English titles only**, with the structure of all 66
   books. No other language is in the first tag, whatever passes its gates
   by 13 Nov.
2. **The other nine v0.1 languages follow in v0.1.x** (ar, es-419, fr, hi,
   id, pt-BR, ru, sw, zh-Hans; ADR [0002](0002-measure-translation-models.md)),
   once the translation model is chosen on #64 and each language passes its
   gates.
3. **The ask for an es-419 or French reviewer** (#64) goes out for v0.1.1,
   not for v0.1.0.

## What changes and what does not

ADR 0003 decision 1 reads: "A gated subset: all structure and English
titles; the languages that pass the gates by 13 Nov; the rest in v0.1.x."
This decision changes only the middle clause, for v0.1.0: no language other
than English is in it, so the 13 Nov languages item is off the critical
path. That case was already allowed by ADR 0003 ("the rest in v0.1.x") and by
the subset order in [`../scoping/plan.md`](../scoping/plan.md).

Not changed:

- **Structure and English.** All 66 books' pericopes and segments, and their
  English titles, as ADR 0003 and ADR [0005](0005-go-no-go-1-ai-checked-english.md)
  set them.
- **The v0.1 languages.** The same nine, the same `es-419` tag (ADR 0003
  decision 13) and the same zh-Hans key-term route (decision 14).
- **How the model is chosen.** ADR 0002's rule, and the maintainer's 3 Nov
  hold on #64 (wait for one more complete review, es-419 or French, before
  choosing).
- **Go/no-go 2 (13 Nov) still runs.** It checks English and `dist/`, not
  other languages (`../scoping/plan.md`).

## Evidence

- **No other language is in the build today.** `data/titles/` and
  `dist/tc-mobile/titles/` each hold only `en/` (listed with `ls` on
  5 Nov 2026, branch base `3b4cc37`). So shipping English only needs no
  change to the build.
- **The model choice is not made.** #64's last comment (3 Nov): the
  maintainer holds the choice until at least one more language (es-419 or
  French) has a complete review, and "the v0.1 translation run waits until
  then". Read on 5 Nov.
- **Adding a language later needs no key change.** Under `../schema.md`,
  "Releases", a release with no key changes is a patch, so the languages fit
  v0.1.x. (Those version rules are assumed from the tc-mobile contract and
  not yet checked by the release workflow, as that section says.)

## Why

- The translation run cannot start until the model is chosen, and the
  choice waits on a reviewer who has not been found. Keeping languages on the
  13 Nov path would tie the English release to that wait.
- tC Mobile needs real data for the whole Bible to test its template
  library (ADR 0005, "Why"). English for 66 books meets that.
- A language shipped later is a smaller, checkable release of its own, in
  line with "Progress over perfection" (AGENTS.md).

## Rejected

- **Hold v0.1.0 for the languages that pass by 13 Nov.** No language can
  pass before the model is chosen, so this would add nothing to the tag and
  keep a gate on the critical path that cannot be met.

## Consequences

- v0.1.0's release notes say it is English only and that the nine languages
  follow in v0.1.x.
- `../scoping/plan.md`'s 13 Nov gate is about English; its languages row
  moves to v0.1.x.
