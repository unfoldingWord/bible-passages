Bible Passages

Every passage of the Bible, divided into stories and the short segments a translator records, each with a plain title in the translator's own language. It lets a translator find the place in the story without chapter and verse.

Baseline snapshot
Where it stands · 28 Oct 2026
  • The repo exists and is scaffolded (PR #1, in review by the review bench). No data yet. tC Mobile's own template checker runs in CI.
  • Every base count is measured and independently re-derived: 3,016 pericopes, 13,608 chunks, 162 splits, so 13,770 segments and 16,786 English titles. The pilot's 194 splits came from a Psalms parsing quirk.
  • The constraint now is decisions. Scope, keys and which chunk source is authoritative decide what gets built. ULT's chunk markers and the chunk files disagree at 1,184 places. See Decisions.
  • Next gate: Titus built end to end by 1 Nov, so the rest of the plan is sized from measured rates, not guesses. See Plan.
