# Contributing

Read [`AGENTS.md`](AGENTS.md) first: the rules, commands and review process
live there. The data shape is in [`docs/schema.md`](docs/schema.md).

- **Pick up work by assigning yourself** to an open, unassigned issue before
  you start. Every PR needs an assignee and a linked, assigned issue; CI
  checks it. See [`AGENTS.md`](AGENTS.md), "All work is assigned".
- Open issues on this repo. Scope questions about the dataset as a whole go to
  [unfoldingWord/servant.bible#1](https://github.com/unfoldingWord/servant.bible/issues/1).
- Questions and discussion: [forum.door43.org](https://forum.door43.org).
- Security reports: see [`SECURITY.md`](SECURITY.md), never a public issue.

By contributing you agree that data contributions are licensed CC BY-SA 4.0
and code contributions MIT, as described in the [README](README.md).
